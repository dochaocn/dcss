# 执行 Shell 命令

仅在用户显式调用 `/shell` 时使用本技能。

## 行为约定

1. 将用户在 `/shell` 之后的全部文字视为要运行的 **字面 shell 命令**。
2. 立即用终端工具执行该命令。
3. 运行前 **不要** 改写、解释或「优化」命令。
4. **不要** 先浏览仓库，除非命令本身需要仓库上下文。
5. 若用户只输入 `/shell` 而没有后续命令，请询问要执行哪条命令。

## 回复方式

- 先执行命令。
- 再简要说明退出码，以及重要的标准输出或标准错误。
