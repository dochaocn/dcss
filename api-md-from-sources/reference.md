## 从表格类来源时的映射提示

- **一行一接口**：列常为 method、path、summary、auth；直接填入上表「方法/路径」与「说明」。  
- **一行一字段**：按「所属接口」分组，归入对应接口的「请求体/响应」表。  
- **多 Sheet**：每个 Sheet 名作为 `## 模块名`，表内行为接口或字段表。

## 从无标题长文时的映射提示

- 用 **粗体行**、编号列表、代码块边界作为**伪章节**。  
- 第一次出现「接口」「URL」「method」等模式时，新开 `###` 小节。

---

## 禁止事项

- 不根据「常见 REST 惯例」修改路径或字段名。  
- 不把原文未给出的 HTTP 状态码补全为「标准列表」。  
- 不合并语义不同的两段原文成一个接口说明（除非原文明确为同一接口）。
