## 核心思维框架

以下六个框架是毛泽东思想的精髓。面对任何问题，先判断适用哪个框架，然后按步骤展开。

### 一、矛盾分析法（《矛盾论》）

**核心命题**：对立统一规律是宇宙的根本规律。

**步骤**：

1. **找矛盾**——任何事物内部都有矛盾。列出这个局面中的所有矛盾对。没有矛盾就没有世界，差异本身就是矛盾。

2. **抓主要矛盾**——"在复杂事物的发展过程中，有许多矛盾存在，其中必有一种是主要的矛盾，由于它的存在和发展规定或影响着其他矛盾的存在和发展。"集中精力找出那个起决定性作用的矛盾。捉住了主要矛盾，一切问题就迎刃而解。

3. **分析矛盾的主要方面**——每一矛盾的两个方面，必有一方占主导地位。事物的性质主要由取得支配地位的矛盾的主要方面所规定。要判断当前哪一方占优、能否转化。

4. **考察矛盾的转化条件**——"矛盾着的双方，依据一定的条件，各向着其相反的方面转化。"分析什么条件能让矛盾的主要方面发生转移。鸡蛋能变鸡，石头不能——关键在内部根据+外部条件。

5. **注意矛盾的特殊性**——"不同质的矛盾，只有用不同质的方法才能解决。"不要千篇一律套公式。具体问题具体分析是马克思主义的活的灵魂。

**关键金句**：
- "外因是变化的条件，内因是变化的根据，外因通过内因而起作用。"
- "矛盾的普遍性即寓于矛盾的特殊性之中。"
- "事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的。"

### 二、实践论（《实践论》）

**核心命题**：认识来源于实践，又回到实践中去检验和发展。

**步骤**：

1. **从实际出发，不要从定义出发**——先搞清楚"事情到底什么样"，而不是"按道理应该什么样"。

2. **感性认识→理性认识**——观察现象（感性阶段），再提炼规律和本质（理性阶段）。"感觉到了的东西，我们不能立刻理解它，只有理解了的东西才能更深刻地感觉它。"

3. **理论要经过实践检验**——"真理的标准只能是社会的实践。"任何分析和方案，都要想清楚它怎么落地、怎么验证。

4. **循环往复**——"实践、认识、再实践、再认识，这种形式循环往复以至无穷。"不要指望一次分析就穷尽真理。

**关键金句**：
- "你要知道梨子的滋味，你就得变革梨子，亲口吃一吃。"
- "没有调查，就没有发言权。"（《反对本本主义》）

### 三、阶级分析法

**核心命题**：经济地位决定政治态度。分析任何社会问题，都要看各方站在哪个阶级的立场上。

**步骤**：

1. **看经济基础**——各方的利益从哪里来？谁给谁打工？谁靠谁吃饭？

2. **看政治态度**——经济利益决定了他们在当前问题上的立场。

3. **看力量对比**——分清敌我友。"谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。"

4. **看同盟可能性**——是否有中间力量可以争取？是否有次要矛盾可以利用？

在现代语境中，"阶级"可以替换为利益集团、阶层、角色群体等，但逻辑不变。

### 四、实事求是

**核心命题**："实事"就是客观存在的一切事物，"是"就是客观事物的内部联系（规律性），"求"就是我们去研究。

**步骤**：

1. 先清空预设——"不凭主观想象，不凭一时的热情，不凭死的书本，而凭客观存在的事实"
2. 详细占有材料——调查研究，了解全面情况
3. 去粗取精、去伪存真、由此及彼、由表及里——从材料中提炼规律
4. 按实际情况决定工作方针——不搞教条主义，不搞经验主义

**两大敌人**：
- **教条主义**：拿书本公式硬套现实
- **经验主义**：把局部经验当普遍真理

### 五、群众路线

**核心命题**："从群众中来，到群众中去。"

**步骤**：

1. 将群众的分散意见集中起来（化为系统意见）
2. 再到群众中宣传解释（化为群众行动）
3. 在群众行动中检验这些意见是否正确
4. 如此无限循环，一次比一次更正确

做决策不能脱离实际使用者/受众的需求和反馈，这个逻辑放任何领域都成立。

### 六、战略与战术

**核心命题**："在战略上我们要藐视一切敌人，在战术上我们要重视一切敌人。"

**几个关键原则**：

- **集中优势兵力，各个击破**——不在所有点上平均用力，找出最薄弱的突破口，集中资源打歼灭战
- **打得赢就打，打不赢就走**——灵活机动，不逞英雄
- **战略持久，战术速决**——大局看长期趋势（持久战），具体战役追求速战速决
- **防御中的进攻，持久中的速决，内线中的外线**——在不利中找有利，在被动中求主动
- **不打无准备之仗**——每战集中绝对优势兵力，力求全歼

## 分析问题的标准流程

当用户要求你用毛泽东的思维分析问题时，按以下步骤：

1. **了解决策背景**——谁在什么情况下要做什么决定？（实践论：从事实出发）

2. **列出矛盾清单**——这个局面中有哪些对立统一的关系？（矛盾论第一步）

3. **抓主要矛盾**——哪一个矛盾是决定性的？（矛盾论第二步）

4. **分析力量对比**——各方利益是什么？谁站在哪一边？谁可以争取？（阶级分析）

5. **判断发展阶段**——是量变还是质变？矛盾是否到了转化的临界点？（矛盾论：阶段性）

6. **提出行动方针**——用什么方法解决什么矛盾？（不同质的矛盾用不同质的方法）

7. **考虑风险与韧性**——最坏情况是什么？如何做到"战略上藐视，战术上重视"？

## 注意事项

- **不要生搬硬套**——毛泽东分析的是 20 世纪中国革命，具体结论不能直接套用到所有场景。学的是**方法**，不是**结论**。
- **分析完要有行动指向**——毛泽东思想是行动哲学，不是为了分析而分析。每次分析最后必须落到"怎么办"。
- **引用原文要准确**——不要凭记忆复述毛选内容，用 search_files + read_file 查原文。
- **革命话语可以视语境调整**——把"革命""斗争""敌人"等概念翻译成当前问题中对应的范畴即可，精神不变。
- **本版本为静火版**——1-7 卷，第七卷仅 2 篇，非官方完整版。Markdown 格式，可能含少量 OCR 错误。
